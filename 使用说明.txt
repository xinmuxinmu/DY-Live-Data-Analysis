=========================================================
  DY直播数据分析（Python 版）· 使用说明
=========================================================

【这是什么】
  原「DY直播数据分析」是 .NET / WinForms 程序。本版本是按原软件的功能
  与界面结构，用 Python + PySide6(Qt) 等价重写的一套源码工程，
  可直接运行、可二次开发。

  特点：
    · 界面用 PySide6（Qt Widgets），与原 WinForms 观感一致
    · 除 PySide6 外不依赖任何第三方包（其余全部是 Python 标准库）
    · 录制 / 预览 / 转换需要 ffmpeg，仓库不附带二进制，获取方式见下
    · 无登录、无激活、无联网校验

【运行环境】
  · Windows 7 / 10 / 11
  · Python 3.8 或更高版本（安装时勾选 Add Python to PATH）
  · PySide6（见下方「安装依赖」）

【安装依赖】
  程序界面依赖 PySide6。若尚未安装，在命令提示符里执行：

      pip install PySide6-Essentials

  说明：只需要 Essentials（含 QtWidgets / QtCore / QtGui / QtCharts），
  不必装完整的 PySide6-Addons。
  若 pip 下载慢，可换镜像：
      pip install PySide6-Essentials -i https://mirrors.aliyun.com/pypi/simple/

  启动.bat 会自动在机器上寻找「已装 PySide6」的那个 Python 解释器，
  找到就直接用，找不到才提示你安装。

【安装 ffmpeg（录制 / 预览 / 转换需要）】
  ffmpeg.exe / ffplay.exe / ffprobe.exe 需要自备，仓库不附带二进制。
  任选一种方式：
    方式一：把 ffmpeg 放到  程序目录/ffmpeg/  下（目录名就叫 ffmpeg）
    方式二：把 ffmpeg 加入系统 PATH
    方式三：设环境变量 DY_FFMPEG 指向 ffmpeg.exe 的完整路径
  下载地址（任选其一）：
    · https://www.gyan.dev/ffmpeg/builds/      （Windows release 构建）
    · https://github.com/BtbN/FFmpeg-Builds/releases   （Windows 构建）
    · https://ffmpeg.org/download.html
  「下载流」录制方式不依赖 ffmpeg，但 ts/mp4 录制、直播预览、视频转码都需要。
  程序会在启动日志里写明是否找到 ffmpeg，工具栏状态栏也会显示「ffmpeg：已就绪」。

【启动方式】
  方式一：双击  启动.bat        ← 推荐（自动挑选正确的解释器，无控制台窗口）
  方式二：命令行  python main.py
  方式三（无界面）：python main.py cli hot -n 30
                    python main.py cli selftest     # 签名算法自检

【快速上手】
  1. 点「＋ 添加主播」，支持四种输入（都可直接识别）：
       · 抖音号         例：XINMU__   （可不带 @，无需登录）
       · 主播主页链接   例：https://www.douyin.com/user/MS4wLjABAAAA…
       · 主播唯一码     例：MS4wLjABAAAA…
       · 直播间链接     例：https://live.douyin.com/123456789
     点「识别」→ 显示昵称 / 粉丝 / 获赞 → 点「添加」。
  2. 在主列表里双击「是否监控」「是否录制」两列切换开关，
     或右键「当前主播_加入监控 / 加入录制」。
  3. 点「▶ 开启监控录制」，程序按设定间隔轮询，开播自动录制。
     · 只要列表里存在「监控」中的主播，添加/导入后会自动开启监控，
       不需要再手动点一次。
     · 录制过程中点工具栏「⏹ 一键停止录制」（快捷键 F9）可立即停止全部录制。

  批量添加：菜单「文件 → 批量导入主播」，每行一个抖音号或链接，可从文件读取。
  找热门：工具栏「热门直播」，选中后点「加入监控」。

【功能清单】
  · 主播管理：添加 / 批量导入 / 删除 / 独立设置 / 排序 / 移动至序号
  · 抖音号识别：抖音号、主页链接、唯一码、直播间链接四种输入
  · 开播监控：按间隔轮询，检测开播、关播、在线人数变化
  · 自动录制：两种「录制方式」可选，支持
      - 清晰度：原画 / 超清 / 高清 / 标清 / 流畅
      - 分段录制（每 N 分钟一段，文件名为 xxx_001.mp4、xxx_002.mp4…）
      - 录满 N 分钟自动停止
      - 录制内容：视频 / 音频（.m4a）
      - 一键停止全部录制（F9）
  · 录制方式（对应原软件 Frm_Main 的 rdbtn_录制流 / rdbtn_下载流）：
      - 录制流（默认）：用 ffmpeg 录制，保存 ts/mp4，播放器可直接播放
      - 下载流：直接下载 FLV 流，保存 .flv，无法播放需转码
        特点：断线自动续传（带 Range 从断点继续）、只写完整 FLV tag，
        任何时候中断文件都不损坏；不支持 Range 的源自动换新文件继续录。
        原软件说明：「如果选择录制，无法录制，就选下载方式；反之亦然。」
  · 提醒：开播 / 关播 / 开始录制 / 停止录制 / 在线人数达标提示音
      （自定义 wav 放入 软件数据/提示音/）
  · 群机器人推送：企业微信 / 钉钉 / 飞书 / 自定义 Webhook
  · 数据采集：每次开播写入一条记录，按天存 CSV
  · 导出：主播数据 Excel、采集记录 Excel（内置 xlsx 生成器）
  · 数据统计：各主播最高在线柱状图（QtCharts 原生图表）+ 采集明细
  · 录制设置：录制方式 / 默认录制内容 / 质量 / 分段 / 录满停止 / 录制目录 / 转码选项
  · 视频转码：录制后无损转码 MP4、压缩、提取 MP3（ffmpeg）
  · 浏览器设置：内置浏览器 / 外部浏览器、用户数据目录、清理缓存与登录信息
  · 直播流预览：调用 ffplay 直接播放当前流地址
  · 运行日志：按天记录，界面内查看

【常见问题】
  Q：双击 启动.bat 没反应 / 提示找不到 Python？
  A：启动.bat 会在 PATH 上逐个探测能 import PySide6 的解释器。
     若提示 No usable Python + PySide6 was found，说明当前机器上的
     Python 都没装 PySide6，按提示执行 pip install PySide6-Essentials。

  Q：提示「接口返回空响应（被风控拦截）」？
  A：抖音对高频请求有限制。请调大「设置 → 监控间隔」（建议 ≥ 30 秒），
     减少同时监控的主播数量，或稍后重试。

  Q：添加主播时提示「无法识别」？
  A：请检查输入格式。支持抖音号（如 XINMU__）、主页链接、唯一码、
     直播间链接四种。若抖音号识别失败，多为抖音号不存在或已被风控
     限流，可稍后重试；也可改用主播主页链接。

  Q：录制目录是空的，没有录到东西？
  A：按以下顺序排查：
     1）该主播的「是否监控」「是否录制」两列都要打开（显示 ✔）；
     2）工具栏按钮需处于「■ 停止监控录制」状态，即监控正在运行；
     3）主播当时确实在开播——未开播自然不会产生文件；
     4）看「录制状态」列是否为「录制中」，底部日志有无报错。
     程序对「监控中」的主播会自动轮询检测，无需手动点检测。

  Q：为什么「直播标题」列有时是空的？
  A：主播主页接口不返回直播标题（只有抖音的直播间详情接口返回，而该接口
     当前被风控拦截）。从「热门直播」加入的主播会有标题。

  Q：录制失败，提示未取到直播流地址？
  A：部分直播间不对外提供流地址（仅粉丝可见、付费直播、未开播）。

  Q：未找到 ffmpeg？
  A：确认程序目录下有 ffmpeg 文件夹，且包含 ffmpeg.exe、ffplay.exe、
     ffprobe.exe 及同目录的 DLL 文件。也可设置环境变量 DY_FFMPEG
     指向 ffmpeg.exe。

  Q：想打包成单个 exe 交付？
  A：pip install pyinstaller 后执行：
       pyinstaller -F -w -n "DY直播数据分析" main.py
     再把 ffmpeg 文件夹复制到 exe 同目录即可。
